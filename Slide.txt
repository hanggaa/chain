## 📉 Slide 2: Jenis RPC Request & Beban API Bulanan
*Transaksi on-chain tidak hanya memerlukan Write (`storeHash`), melainkan banyak Read query untuk verifikasi.*

### 1. Estimasi API Request Bulanan (Asumsi 6.000 Invoice Baru/Bulan):
* **Write Request (`storeHash`)**: **~6.000 call/bulan** (1 call per invoice baru).
* **Read Request (`documentExists`)**: **~30.000 call/bulan** (Pengecekan duplikasi otomatis di dashboard & verifikasi internal).
* **Read Request (`verifyDocument`)**: **~15.000 call/bulan** (Melalui verifikasi manual / QR code halaman `verify.html`).
* **Total API Load**: **~51.000 RPC call/bulan**.

### 2. Aturan Gas & Pembiayaan:
* **Write Call (`eth_sendTransaction`)**: Memerlukan gas fee riil dibayar ke validator blockchain.
* **Read Call (`eth_call`)**: Bersifat lokal pada node, **100% gratis (tanpa biaya gas)** tetapi memakan kuota *bandwidth* (credits) RPC Provider.

## ⚡ Slide 4: Kecepatan Konfirmasi & Finalitas Jaringan
*Analisis Latensi dan Kecepatan untuk memproses transaksi (UX) serta jaminan finalitas data.*

* **Arbitrum Mainnet**:
  * **Block Time**: **~250ms** (Tercepat, respons langsung).
  * **Soft Finality (Sequencer)**: **~250ms** (Sangat instan).
  * **Hard Finality (L1 Settlement)**: **~13 menit** (Waktu posting batch data L2 ke Ethereum L1).
* **Base Mainnet**:
  * **Block Time**: **~2 detik** (Memiliki fitur pre-confirmations Flashblocks hingga **~200ms** untuk pembayaran/UX cepat).
  * **Soft Finality (Sequencer)**: **~200ms**.
  * **Hard Finality (L1 Settlement)**: **~13 menit**.
* **Optimism Mainnet**:
  * **Block Time**: **~2 detik** (Memproses batch reguler).
  * **Soft Finality (Sequencer)**: **~2 detik** (Menengah).
  * **Hard Finality (L1 Settlement)**: **~16 menit**.
* **Polygon PoS**:
  * **Block Time**: **~1.75 detik** (Baru saja dioptimalkan dari 2 detik).
  * **Soft Finality (Validator)**: **~2 detik**.
  * **Hard Finality (L1 Checkpointing)**: **~5 menit** (Menggunakan checkpointing terpisah, tidak melewati fraud proof 7 hari).

## 🔐 Slide 6: Analisis Keandalan Jaringan (Data Downtime 2024–2026)
*Berdasarkan status resmi insiden stabilitas jaringan selama 2 tahun terakhir.*

* **Arbitrum Mainnet (Uptime: 99.99%)**:
  * *Status*: Terstabil.
  * *Downtime*: **0 menit** downtime sequencer tidak terencana.
* **Optimism Mainnet (Uptime: 99.95%)**:
  * *Status*: Sangat stabil.
  * *Downtime*: Mengalami instabilitas "unsafe head stall" sequencer selama **beberapa jam** di awal 2024. Setelah itu, 100% aktif selama 2025–2026.
* **Base Mainnet (Uptime: 99.90%)**:
  * *Status*: Menengah.
  * *Downtime*: Henti produksi blok total selama **29 menit** pada Agustus 2025. Terjadi bug sinkronisasi state L1 selama **30 jam** pada Mei 2026 (transaksi internal L2 tetap diproses).
* **Polygon PoS (Uptime: 99.85%)**:
  * *Status*: Terendah.
  * *Downtime*: Konsensus Heimdall layer mati total selama **1 jam** pada Juli 2025. RPC node gratisan sering mengalami degradasi performa/timeout beberapa jam sekali.

## 🌐 Slide 7: Analisis RPC Provider & Peta Biaya Operasional
*Analisis konsumsi 51.000 API calls/bulan (campuran read & write).*

1. **Alchemy (Compute Unit - CU)**:
   * *Free Tier*: 30 Juta CU/bulan.
   * *Beban Kita*: Rata-rata panggilan `storeHash`/`verifyDocument` memakan ~27 CU. Total 51.000 call $\approx$ **1,37 Juta CU/bulan** (Sangat aman di bawah limit gratis).
   * *Overage*: $0.45 per 1 juta CU.
2. **Infura (Credit System)**:
   * *Free Tier*: 3 Juta Credit per hari $\approx$ 90 Juta Credit/bulan.
   * *Beban Kita*: ~51.000 credit/bulan (Sangat aman, gratis selamanya untuk kapasitas ini).
3. **Chainstack (Request Unit - RU)**:
   * *Free Tier*: 3 Juta RU/bulan.
   * *Beban Kita*: Menggunakan skema flat 1 request = 1 RU. Total **51.000 RU/bulan** (Sangat aman di bawah limit gratis).
4. **QuickNode (API Credits)**:
   * *Free Tier*: 10 Juta API Credits/bulan.
   * *Beban Kita*: Mengonsumsi sekitar 1,5 Juta Credits/bulan. (Aman di bawah limit gratis).

## 🎯 Slide 8: Rekomendasi Akhir & Next Step
* **Jaringan Utama Pilihan**: **Optimism Mainnet**.
  * *Alasan*: Biaya gas bulanan termurah (~$1.33 untuk 7.000 invoice), uptime sangat stabil (99.95%), dan menggunakan ETH yang memiliki volatilitas harga lebih terkendali dibanding POL.
* **RPC Provider Terbaik**: **Infura** (Menawarkan limit harian 3 Juta Request yang sangat stabil dan memiliki response-time cepat untuk verifikasi QR Code).
* **Strategi Mitigasi**: 
  1. Melakukan hedging (pembelian berkala) koin gas ETH senilai kebutuhan 6 mobil operasional ke depan untuk mengunci biaya operasional tetap.
  2. Menerapkan skema multi-node RPC (Infura sebagai endpoint utama, Alchemy sebagai fallback) pada aplikasi Fintech1000s untuk menjamin ketersediaan 100%.
